# 2026-07-11 C파트 작업 로그

## 작업 범위

담당 범위는 백엔드 C파트 중심으로 진행했습니다.

- 공고 기술스택 매핑
- 공고 기반 담당업무 분석 API
- 공고와 이력서 키워드 비교
- 이력서 CRUD
- 이력서 프로젝트 CRUD
- AI 추천/피드백 API 초안
- 로컬 테스트용 MariaDB 샘플 데이터 구성

## 완료한 내용

### 1. 공고 기술스택 매핑

공고 제목, 직무 키워드, 공고 원문 텍스트에서 기술스택 키워드를 추출하도록 구현했습니다.

- `ReactJS`, `React.js`는 `React`로 통합
- `SpringBoot`는 `Spring Boot`로 통합
- `RestAPI`, `RESTful API`는 `REST API`로 통합
- 추출된 기술스택은 카테고리와 함께 응답에 포함

관련 코드:

- `SkillMappingService`
- `JobNoticeSnapshot`
- `SkillMatch`

### 2. 공고 기반 담당업무 분석 API

공고 ID를 기준으로 공고 정보를 조회하고, 기술스택 기반으로 담당업무 예측 결과를 반환하도록 구현했습니다.

Endpoint:

```text
POST /job-notices/{jobNoticeId}/ai-analysis
```

현재는 실제 OpenAI 연동 전 단계입니다.
즉, AI API를 직접 호출하지 않고 규칙 기반 mock 분석 결과를 생성합니다.

응답에 포함되는 주요 값:

- `taskSummary`
- `requiredSkills`
- `mappedSkills`
- `possibleTasks`
- `analyzedAt`

### 3. 공고-이력서 키워드 비교

공고 기술스택과 이력서 기술스택을 비교해 겹치는 키워드와 부족한 키워드를 계산하도록 구현했습니다.

Endpoint:

```text
POST /job-notices/{jobNoticeId}/resume-keywords
```

주요 계산 내용:

- `matchedKeywords`: 공고와 이력서에 모두 있는 기술
- `missingKeywords`: 공고에는 있지만 이력서에는 없는 기술
- `jaccardScore`: 공고 기술스택과 이력서 기술스택의 단순 집합 유사도
- `recommendedReason`: 보완 방향 안내 문구

Jaccard 점수는 정량 비교용이고, Java와 C처럼 의미적으로 유사하지만 키워드가 다른 경우는 이후 AI 피드백에서 보완하는 방향으로 정리했습니다.

### 4. 이력서 CRUD

이력서를 DB에 저장하고 조회, 수정, 삭제할 수 있도록 구현했습니다.

Endpoints:

```text
POST /resumes
GET /resumes
GET /resumes/{resumeId}
PATCH /resumes/{resumeId}
PATCH /resumes/{resumeId}/default
DELETE /resumes/{resumeId}
```

저장 테이블:

- `resumes`

주의:

- 현재는 인증 연동 전 단계라 임시로 `user_id = 1` 기준으로 저장합니다.
- 로컬 테스트 전 `users` 테이블에 `user_id = 1` 샘플 데이터가 필요합니다.

### 5. 이력서 프로젝트 CRUD

이력서 안에 들어가는 프로젝트 경험을 별도 테이블로 관리하도록 구현했습니다.

Endpoints:

```text
POST /resumes/{resumeId}/projects
PATCH /resumes/{resumeId}/projects/{projectId}
DELETE /resumes/{resumeId}/projects/{projectId}
```

저장 테이블:

- `resume_projects`

이력서 상세 조회 시 같은 `resume_id`를 가진 프로젝트들이 `projects` 배열로 함께 응답됩니다.

### 6. AI 추천/피드백 API 초안

이력서와 공고를 기준으로 보완 피드백을 생성하는 API 구조를 추가했습니다.

Endpoints:

```text
POST /ai-recommendations
GET /ai-recommendations
```

현재는 실제 OpenAI 연동 및 DB 저장 전 단계입니다.
공고-이력서 키워드 비교 결과를 바탕으로 mock 피드백을 생성합니다.
