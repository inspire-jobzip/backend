# 2026-07-13 작업 로그

## Calendar API 구현
- `feature/calendar` 브랜치를 생성하고 Calendar API 작업을 시작했다.
- `GET /api/v1/calendar/job-notices` 전체 공고 마감일정 조회 API를 추가했다.
- `GET /api/v1/calendar/bookmarks` 내 스크랩 공고 마감일정 조회 API를 추가했다.
- 연도/월 필수값과 잘못된 월 값에 대한 400 예외 처리를 추가했다.
- 내 스크랩 일정 조회는 토큰 발급/검증 기능이 아직 없어 `Authorization` 헤더 검증 위치에 JWT 연동 TODO 주석을 남기고 임시 사용자 조회 방식으로 구현했다.
- 공고 상태, 표시 문구, 남은 일수, 색상 타입 계산 로직을 추가했다.
- Calendar 서비스 단위 테스트를 추가했다.
