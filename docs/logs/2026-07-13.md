# 2026-07-13 작업 로그

## 채용공고 상세 조회 마무리
- `jobnotice` 패키지에 있던 `JobNotice`, `JobNoticeRepository` 역할을 `jobNotices` 패키지로 통합했다.
- `AiAnalysisService`의 `jobnotice` 참조를 `jobNotices`의 `JobNotices`, `JobNoticesRepository` 참조로 변경했다.
- 기존 JDBC class 형태의 `JobNoticesRepository`를 JPA `JpaRepository` 기반 interface로 변경했다.
- 목록/상세 조회용 native query는 Repository interface의 projection과 default method로 옮겨 기존 서비스 응답 변환 흐름을 유지했다.
- Repository interface 전환에 맞춰 서비스 테스트를 Mockito 기반으로 수정했다.
- `BackendApplicationTests`에 필요한 Repository mock을 추가해 context load 테스트를 보강했다.
