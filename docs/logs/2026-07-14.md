## Job AI Analysis API OpenAI 연동
- `feature/ai-analysis` 브랜치를 생성하고 공고 기반 담당업무 AI 분석 기능을 이어서 구현했다.
- OpenAI Chat Completions API 호출을 담당하는 client를 추가했다.
- 공고 분석 결과를 `job_notices.ai_analysis_json`에 저장하고, 기존 분석 결과가 최신이면 캐시를 반환하도록 변경했다.
- `job_notices.updated_at`이 기존 `analyzedAt`보다 최신이면 OpenAI 재분석을 수행하도록 처리했다.
- AI 분석 응답 DTO를 API 명세의 `taskSummary`, `requiredSkills`, `analyzedAt` 구조에 맞게 정리했다.
- 캐시 사용, 재분석, 공고 미존재 예외를 서비스 단위 테스트로 검증했다.
- AI 분석 캐시 판단, OpenAI JSON 응답 요청, 토큰 절약 처리 의도를 간단한 주석으로 보강했다.
- 원격 `develop` 병합 충돌을 `develop` 구조 우선으로 정리하고, 공고 수정 시 AI 분석을 재수행하는 캐시 최신성 로직을 다시 반영했다.
- 기존 `develop`의 OpenAI 분석 클라이언트는 유지하고, 담당업무 분석 API 명세 전용 프롬프트 클라이언트를 새로 연결했다.
- 담당업무 분석 응답이 `taskSummary`, `requiredSkills`, `possibleTasks`, `analyzedAt`만 노출되도록 정리했다.
- 채용공고 상세조회에서 인증 사용자의 대표이력서 기술스택과 공고 기술스택을 비교해 `jaccardScore`를 계산하도록 변경했다.
- 대표이력서 기술스택에 Swagger 기본값인 `string`이 저장된 경우를 제외하고, 이력서 프로젝트 기술스택까지 합산해 `jaccardScore`를 계산하도록 보완했다.
