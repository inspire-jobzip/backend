## 채용공고 상세 조회 구현
- `GET /api/v1/job-notices/{jobNoticeId}` 상세 조회 API를 추가했다.
- 공고 상세 응답에 외부 공고 ID, 원문 URL, 학력, 급여, 원문, 기술스택, 북마크 여부, 유사도 점수를 포함했다.
- 존재하지 않는 공고는 `JOB_NOTICE_NOT_FOUND` 404 응답으로 처리했다.
- `jobNoticeId` 형식 오류는 400 공통 실패 응답으로 처리했다.
- 상세 조회 서비스 테스트를 추가했다.

## Bookmark API 구현
- `feature/bookmark` 브랜치를 생성하고 Bookmark API 작업을 시작했다.
- `POST /api/v1/job-notices/{jobNoticeId}/bookmark` 공고 스크랩 등록 API를 추가했다.
- `DELETE /api/v1/job-notices/{jobNoticeId}/bookmark` 공고 스크랩 취소 API를 추가했다.
- `GET /api/v1/bookmarks` 내 스크랩 공고 목록 조회 API를 추가했다.
- 토큰 발급/검증 기능이 아직 없어 `Authorization` 헤더 검증 위치에 JWT 연동 TODO 주석을 남기고 임시 사용자 조회 방식으로 구현했다.
- Bookmark 서비스 단위 테스트를 추가했다.

## Bookmark Entity 정리
- `docs/database/erd-plan.md`와 `docs/database/ddl.sql`의 `bookmarks` 테이블 구조를 기준으로 `BookmarkEntity`를 추가했다.

- Bookmark 엔티티 추가 전제로 남아 있던 jobNotices 엔티티 임시 주석을 제거했다.
